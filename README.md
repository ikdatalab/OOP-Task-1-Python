# OOP Assignment 1 (Python)

Python Object-Oriented Programming ki task-1 ke solutions. Har question ek alag class ya concept par based hai.

## Questions

| Q | Topic | Class |
|---|-------|-------|
| 1 | Student grades (constructor, methods) | `Student` |
| 2 | Class vs instance attribute shadowing | `BankBranch` |
| 3 | Static utility methods | `RetailUtility` |
| 4 | Encapsulation and private methods | `OrderProcessing` |
| 5 | Account ledger with transaction history | `KhyberTextileAccount` |
| 6 | Electricity bill with slab rates | `KElectricBilling` |

## Concepts Covered
- Classes and constructors (`__init__`)
- Class attributes vs instance attributes
- `@staticmethod`
- Encapsulation (`_private` methods)
- Dictionaries and lists for data storage

## How to Run
1. Python 3.12+ install karo
2. `OOP_Assignment1.ipynb` ko Jupyter ya VS Code mein kholo
3. **Run All** karo
